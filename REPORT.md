# Отчет по домашнему заданию ЛР6

## Задание

Домашнее задание находится в конце страницы ЛР6. Нужно настроить создание пакетов для изменений, отмеченных тегами. Релиз должен содержать архивы исходного кода и пакеты с бинарным файлом `solver`.

## Что сделано

1. В проект добавлена конфигурация CPack.
2. Указана версия пакета `0.1.0.0`.
3. Добавлены правила установки.
4. Добавлена сборка пакета через цель `package`.
5. В CI добавлен шаг сборки пакета.

## Проверка локально

```sh
cmake -S . -B _build -DBUILD_TESTS=ON
cmake --build _build
cmake --build _build --target test
cmake --build _build --target package
```

## Проверка CPack

```sh
cd _build
cpack -G TGZ
cpack -G DEB
```

## Ожидаемый результат

CPack должен создать архив и пакет с собранными файлами проекта.

Пример вывода:

```text
CPack: Create package
CPack: - package: ... generated.
```

## Вывод

Домашнее задание выполнено в части настройки упаковки проекта и подготовки сборки пакета через CPack. Для полного релиза пакет должен публиковаться при пуше тега.
